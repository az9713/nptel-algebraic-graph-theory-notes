1. Graphs, routes and the spanning-tree question

A communication network has six available links connecting five devices. Which four links can carry communication between every pair of devices, without retaining a cycle? Counting those possible backbones is a graph problem. The surprising next step is that a determinant can do the counting.

The network used throughout this chapter is an original teaching construction. Its vertices are $V=\{0,1,2,3,4\}$ and its edges are $E=\{\{0,1\},\{1,2\},\{2,3\},\{0,3\},\{0,2\},\{2,4\}\}$. A square has one diagonal, and vertex $4$ is attached to vertex $2$. Every link is undirected and unweighted. These assumptions describe possible communication, not latency, capacity or the probability of a failure.

The first recording supplies the sequence of definitions, the three tree exercises, and the determinant-counting question. The proofs below supply the missing steps. The executable enumeration and the five-vertex example are independently authored. Machine transcription supports the topic sequence; no complete transcription of the original board is claimed.

1.1 The objects in a simple graph 01:53

A finite simple undirected graph is a pair $G=(V,E)$. The set $V$ is a finite nonempty set of vertices. Each member of $E$ is a two-element subset of $V$, called an edge. Thus an edge has two distinct endpoints. Writing $\{u,v\}$ emphasizes that $\{u,v\}=\{v,u\}$: the edge has no direction. We write $n=|V|$ for the number of vertices and $m=|E|$ for the number of edges.

Two vertices are adjacent when their pair belongs to $E$. An edge is incident with each of its endpoints. The degree $d(v)$ of a vertex $v$ is the number of incident edges. In Figure 1.1, the degrees in vertex order $0,1,2,3,4$ are $3,2,4,2,1$. Vertex $2$ has four neighbors; vertex $4$ has one. A degree is a property of the specified edge set, rather than of the visual angle or length of a drawn line.

The word “simple” excludes loops and parallel edges. A loop would join a vertex to itself. Parallel edges would give distinct edge identities with the same pair of endpoints. Neither can occur when $E$ is a set of two-element subsets. Directed and weighted graphs carry additional data: an ordered source–target pair or a weight assigned to an edge. Results established under the present convention must be checked again when those data are introduced.

The labels are identifiers. A bijection from $V$ to a new label set, applied to both endpoints of every edge, preserves the possible routes. It does not matter whether a device is called $2$, $v_2$ or a descriptive name. However, retaining the correspondence between labels and matrix rows will matter once the graph is encoded algebraically. A permutation of labels changes an array's appearance without changing the underlying adjacency relation.

Counting incidences. For every finite simple undirected graph, $\sum_{v\in V}d(v)=2m$.

Count pairs consisting of an edge and one of its endpoints. Counting at each vertex gives the sum of the degrees. Counting at each edge gives two pairs, because its endpoints are distinct. Both counts describe the same finite set, proving the equality. For the teaching network, $3+2+4+2+1=12=2\cdot6$. The argument would require a stated convention for how a loop contributes to degree if loops were allowed. ∎

1.2 A walk records a traversal 05:58

A walk of length $k$, where $k$ is a nonnegative integer, is a sequence $(v_0,v_1,\ldots,v_k)$ of vertices such that $\{v_{i-1},v_i\}\in E$ for every $i=1,\ldots,k$. The length counts traversed edges, including repeated uses. A length-zero walk consists of one vertex and traverses no edge. This convention allows a vertex to be reachable from itself without requiring a loop.

In the teaching network, $(0,1,2,1,0,3)$ is a walk of length five. It uses the edge $\{1,2\}$ twice, once in each direction, and also uses $\{0,1\}$ twice. Those are repeated traversals of the same undirected edges. Listing six vertices does not make the length six: a transition occurs between consecutive vertices, so the number of transitions is one less than the number of listed positions.

A walk is closed when its first and last vertices coincide. The walk $(0,1,2,0)$ is closed and has length three. The shorter walk $(0,1,0)$ is also closed, although it goes out and back along a single edge. Later, powers of an adjacency matrix will count walks, so this distinction prevents a closed-walk count from being misread as a count of simple cycles.

A path is a walk whose vertices are all distinct. For example, $(4,2,1,0,3)$ is a path of length four. A cycle is a closed walk of length at least three whose vertices, apart from the repeated first/last vertex, are distinct. Thus $(0,1,2,0)$ is a cycle, but $(0,1,0)$ is not. Calling a cycle a “closed path” is conventional shorthand; our formal definition states exactly which repetition is permitted.

One useful intermediate notion is a trail, a walk that repeats no edge. A trail may repeat a vertex. For example, traversing one cycle and then another cycle that shares only the starting vertex repeats that vertex without repeating an edge. The implications “path implies trail” and “trail implies walk” hold, while their converses do not. The main arguments below need paths and cycles; the extra term helps keep different restrictions separate.

1.3 Reachability and connectedness 11:15

The network can carry a message between $u$ and $v$ when there is a walk from $u$ to $v$. Repeated detours are irrelevant to the existence of communication. The following reduction makes that observation precise and explains why connectedness can be defined using either walks or paths.

Proposition 1.1. If there is a walk from $u$ to $v$, then there is a path from $u$ to $v$.

If the walk repeats a vertex, choose two positions $i<j$ with $v_i=v_j$. Delete the portion between those occurrences, retaining the occurrence at position $i$. If there is a following vertex, it remains adjacent to $v_i$ because it was adjacent to the equal vertex $v_j$. The endpoints are preserved, including the case when the deleted portion ends at the final endpoint. The walk becomes shorter. Repeating the operation must stop because its length is a nonnegative integer and decreases at each deletion. The remaining walk has no repeated vertex, so it is a path. ∎

For $(0,1,2,1,0,3)$, deleting the portion from the first $1$ to the second $1$ gives $(0,1,0,3)$. Deleting the portion between the two occurrences of $0$ then gives $(0,3)$. Both endpoints remain the same, and every intermediate sequence is a valid walk. This is a proof about removing repeated portions, not a claim that a particular implementation finds the shortest route.

A graph is connected when every pair of its vertices is joined by a path. Otherwise it is disconnected. The one-vertex graph with no edges is connected under our length-zero convention. The teaching network is connected. Deleting only the edge $\{2,4\}$ leaves vertex $4$ isolated, so the resulting graph is disconnected even though the square still contains several routes.

For a connected graph, a bridge is an edge whose deletion disconnects the graph. The edge $\{2,4\}$ is a bridge. No alternative route can reach $4$, because every positive-length walk entering or leaving it must use its only incident edge. By contrast, deleting the diagonal leaves the square connected. A large number of alternative backbones elsewhere cannot compensate for this unavoidable leaf connection.

1.4 Ordinary, induced and spanning subgraphs 14:28

A subgraph $H=(S,F)$ of $G=(V,E)$ has $S\subseteq V$, $F\subseteq E$, and both endpoints of every edge in $F$ belong to $S$. Selecting vertices does not force us to retain every available edge between them. On $S=\{0,1,2\}$, the two edges $\{0,1\}$ and $\{1,2\}$ define a path subgraph, even though the ambient graph also contains $\{0,2\}$.

The induced subgraph $G[S]$ retains exactly all ambient edges whose endpoints lie in $S$. Therefore $G[\{0,1,2\}]$ is a triangle, rather than the two-edge path. The adjective “induced” is a completeness requirement for the retained adjacency information. It will later be essential when a principal submatrix is interpreted as the adjacency matrix of a smaller graph.

A spanning subgraph has the full vertex set $V$ and may delete edges. A chosen communication backbone must be spanning: omitting device $4$ from the vertex set would make a smaller graph look connected while failing the original communication task. Keeping an omitted device as an isolated vertex exposes the failure. The distinction between deleting an edge and deleting a vertex changes both the mathematical object and the engineering question.

1.5 Components are maximal, not necessarily largest 17:04

Define a relation on $V$ by declaring $u\sim v$ when a path joins $u$ and $v$. This relation is reflexive because length-zero paths exist. It is symmetric because reversing a path is permitted in an undirected graph. It is transitive because a path from $u$ to $v$ followed by one from $v$ to $w$ is a walk from $u$ to $w$, which Proposition 1.1 reduces to a path. Thus reachability partitions $V$ into equivalence classes.

A connected component is the induced subgraph on one of these classes. This definition agrees with “maximal connected subgraph.” Every vertex in a class is reachable from every other. No vertex outside the class can be added while maintaining connectedness using only ambient edges: a path to such a vertex would put it in the same class. All ambient edges between vertices of the class are included, since adding a missing one could not destroy connectedness.

Maximality concerns inclusion. It means that no larger connected subgraph contains this one. It does not mean that the component has the greatest number of vertices among all connected subgraphs. After deleting $\{2,4\}$ from Figure 1.1, the induced graph on $\{0,1,2,3\}$ and the isolated vertex $\{4\}$ are both components. They have different sizes. The singleton cannot grow inside the fixed ambient graph while remaining connected.

Write $c$ for the number of components. Then $1\le c\le n$ for our nonempty finite graphs. Equality $c=1$ is connectedness. Equality $c=n$ means there are no edges: every vertex is isolated. Each edge lies inside one component because its endpoints are joined by a path of length one. This partition will later let a matrix calculation count connected components without explicitly traversing every route.

1.6 Trees, leaves and the edge-count characterization 21:03

A graph is acyclic when it contains no cycle. A tree is a connected acyclic graph. A forest is an acyclic graph, possibly disconnected. Requiring both conditions matters: two disjoint edges form a forest but not a tree; a triangle is connected but not a tree. The one-vertex graph is a tree.

A vertex of degree one is a leaf, also called a pendant vertex. Its unique incident edge is a pendant edge. We first prove the leaf result asked for in the recording, then use it to obtain the edge count. The hypothesis that a tree has at least two vertices cannot be omitted, because the one-vertex tree has degree zero.

Proposition 1.2. Every finite tree with $n\ge2$ vertices has at least two leaves.

Choose a path with the greatest possible length; one exists because the graph is finite. Since the tree is connected and has at least two vertices, this path contains an edge and has two distinct endpoints. Consider its first endpoint $u$. A neighbor of $u$ outside the path would extend the path, contradicting maximal length. A neighbor on the path other than the next vertex would, together with the intervening path, form a cycle. Acyclicity excludes that possibility. Consequently the next vertex is $u$'s only neighbor, and $d(u)=1$. The same argument at the other endpoint supplies a second leaf. ∎

Proposition 1.3. A finite tree on $n\ge1$ vertices has exactly $n-1$ edges.

Use induction on $n$. At $n=1$, simplicity leaves no possible edge, so the count is zero. For $n\ge2$, Proposition 1.2 provides a leaf. Delete it and its unique edge. No cycle is created by deletion. The remaining vertices stay connected: a path between two of them could not have the deleted leaf as an internal vertex, because an internal vertex of a path needs two incident path edges. Thus the remaining graph is a tree on $n-1$ vertices. By the induction hypothesis it has $n-2$ edges. Restoring the one deleted edge gives $n-1$. ∎

A connected graph always contains a spanning tree. Start with one vertex and no edges. If some vertices remain outside the growing connected set, connectedness gives an edge from the set to its complement: take a path to an outside vertex and locate its first departure. Add that edge and its outside endpoint. The new vertex has only one selected incident edge at this stage, so the selected subgraph remains acyclic. After $n-1$ additions, all vertices are present. The construction proves existence and uses exactly $n-1$ selected edges.

It follows that every connected graph has at least $n-1$ edges. More strongly, a connected graph with exactly $n-1$ edges is itself a tree: its spanning tree already uses $n-1$ edges, so there are no extra edges left. Conversely, a tree is connected and has $n-1$ edges by Proposition 1.3. This proves the second tree exercise from the recording: an $n$-vertex graph with $n-1$ edges that is not a tree must be disconnected.

The count alone is insufficient. A triangle together with an isolated vertex has $n=4$ and $m=3=n-1$, yet it is disconnected and contains a cycle. Nor does a small edge count alone imply a forest: the same triangle with additional isolated vertices keeps its cycle while increasing $n$. Connectivity and acyclicity are logical conditions, not interchangeable numerical labels.

1.7 Count all admissible backbones 27:03

A spanning tree of $G$ is a spanning subgraph that is a tree. It includes every vertex, has $n-1$ edges, and connects every pair. Let $\tau(G)$ denote the number of distinct spanning trees, where two choices are distinct when their edge sets differ. For a disconnected graph, $\tau(G)=0$. For the one-vertex graph, the unique empty edge set is its spanning tree, so $\tau(G)=1$.

Every spanning tree of the teaching network must contain $\{2,4\}$, because otherwise vertex $4$ would be isolated. Removing that forced leaf edge and its leaf leaves a spanning tree of the square with a diagonal on vertices $0,1,2,3$. Conversely, attaching the forced leaf to any such four-vertex spanning tree creates a spanning tree of the full network. This is a bijection, so the leaf does not change the count.

Now separate the four-vertex trees according to whether they use diagonal $\{0,2\}$. Without it, the four square edges must lose exactly one edge. Each of the four omissions leaves a connected path, giving four trees. With the diagonal present, vertices $1$ and $3$ must each be attached to one of the diagonal's endpoints. Vertex $1$ has two choices, $0$ or $2$; vertex $3$ independently has the same two choices. Those $2\cdot2=4$ selections are connected and have three edges, hence are trees. There are no other possibilities because each has already used its three-edge allowance. Therefore $\tau(G)=4+4=8$.

The count describes possible minimal connecting designs. It is not a reliability probability. All eight designs depend on the same pendant edge. If link failures had probabilities, computing communication reliability would require a failure model and would count many connected surviving subgraphs, not only spanning trees. Here the spanning-tree question deliberately isolates the combinatorial structure.

An exhaustive method chooses $n-1$ edges from the $m$ available edges and tests whether they connect all vertices. The number of candidates is $\binom{m}{n-1}$, the number of $(n-1)$-element subsets of an $m$-element set. For our graph there are $\binom64=15$ candidates. That is manageable, but the same method faces $\binom{45}{9}=886{,}163{,}135$ candidates for the complete ten-vertex graph. A complete graph has every possible pair as an edge, so its edge count is $10\cdot9/2=45$. The obstacle is the size of the search space, even before the cost of a connectivity test is considered.

1.8 A determinant finds the same eight 29:58

The adjacency matrix $A$ is the $n\times n$ matrix, indexed by the chosen vertex order, whose entry $A_{ij}$ is one when $i$ and $j$ are adjacent and zero otherwise. Let $D$ be the diagonal matrix of degrees. The combinatorial Laplacian is $L=D-A$. Each row sums to zero: its diagonal is the number of neighbors, and there is one off-diagonal entry $-1$ for each neighbor. These definitions agree with Brouwer and Haemers, Spectra of Graphs, §1.1.

For the teaching network, in vertex order $0,1,2,3,4$, the matrix is

$$L=\begin{pmatrix}3&-1&-1&-1&0\\-1&2&-1&0&0\\-1&-1&4&-1&-1\\-1&0&-1&2&0\\0&0&-1&0&1\end{pmatrix}.$$

Delete the row and column for vertex $2$. The remaining matrix has a separate final entry one, so its determinant reduces to

$$\det\begin{pmatrix}3&-1&-1&0\\-1&2&0&0\\-1&0&2&0\\0&0&0&1\end{pmatrix} =\det\begin{pmatrix}3&-1&-1\\-1&2&0\\-1&0&2\end{pmatrix}=12-2-2=8.$$

A matrix obtained by retaining selected rows and columns is a submatrix; deleting the same row and column produces a principal submatrix. Its determinant here is a principal cofactor of $L$. More generally, deleting row $i$ and column $j$ gives a cofactor only after multiplying the minor's determinant by $(-1)^{i+j}$. Choosing a principal cofactor avoids that sign issue.

The equality with $\tau(G)$ has now been checked in this one explicit graph by two different calculations. That is not a proof for arbitrary graphs. The next chapter derives the matrix-tree theorem from an oriented incidence matrix and the Cauchy–Binet identity. The present question is why a determinant, which combines signed products of entries, should count connected acyclic edge selections with positive weight. Brouwer and Haemers, §1.3.5, gives the general statement and two proof routes.

1.9 Exhaustive enumeration as a finite check

This standard-library program uses the stated five-vertex graph as its only input and prints the number of candidate edge subsets, the number that connect all vertices, and two structural checks. It makes no file or network changes. The connectivity search starts at vertex $0$, repeatedly adds previously unreached neighbors, and succeeds exactly when all five vertices have been reached. Because every candidate already has four edges, the proved connected-$n-1$ criterion identifies a successful candidate as a tree.

from itertools import combinations

vertices = set(range(5))
edges = [(0, 1), (1, 2), (2, 3), (0, 3), (0, 2), (2, 4)]


def connected(choice):
    reached, pending = {0}, [0]
    while pending:
        u = pending.pop()
        for a, b in choice:
            if u not in (a, b):
                continue
            v = b if u == a else a
            if v not in reached:
                reached.add(v)
                pending.append(v)
    return reached == vertices


candidates = list(combinations(edges, len(vertices) - 1))
trees = [choice for choice in candidates if connected(choice)]
assert all((2, 4) in choice for choice in trees)
without_diagonal = [choice for choice in trees if (0, 2) not in choice]
print('candidate subsets:', len(candidates))
print('spanning trees:', len(trees))
print('pendant edge in every tree:', all((2, 4) in t for t in trees))
print('trees without diagonal:', len(without_diagonal))
candidate subsets: 15
spanning trees: 8
pendant edge in every tree: True
trees without diagonal: 4

The search terminates because each vertex enters the pending list at most once. A reached vertex is connected to $0$ by the edges used to discover it. Conversely, if some vertex reachable from $0$ were never discovered, the first undiscovered vertex on a path to it would have a discovered predecessor; processing that predecessor would discover it, a contradiction. This establishes the search invariant independently of its printed answer. Enumeration verifies this small example and the program; the proofs above establish the graph-theoretic criteria used by the program.

1.10 Problems with complete solutions

1. Walk, path or cycle?

Classify $(4,2,0,1,2)$ and $(0,1,2,0)$ in the teaching network. State each length and shorten the first to a path with the same endpoints.

Solution

The first sequence is a walk of length four. Vertex $2$ repeats, so it is not a path; its endpoints differ, so it is not closed and cannot be a cycle. Its four edge traversals are distinct, making it a trail. Delete the portion $2,0,1,2$ between the repeated occurrences of $2$, leaving the length-one path $(4,2)$. The second sequence is a closed walk of length three. Its only repeated vertex is its first/last vertex, so it is a cycle. Under our definition it is not a path, because a path has all vertices distinct.

2. Subgraph data that a vertex set does not determine

For $S=\{0,1,2\}$, list the edge set of $G[S]$. Give a connected subgraph on $S$ that is not induced. Why is neither a spanning subgraph of the five-vertex network?

Solution

The induced edge set is $\{\{0,1\},\{1,2\},\{0,2\}\}$, a triangle. Retaining only $\{0,1\}$ and $\{1,2\}$ gives a connected path but omits an available edge between retained vertices, so it is not induced. Both objects use vertex set $S$, which omits vertices $3$ and $4$. A spanning subgraph must retain the entire ambient vertex set, regardless of whether its retained edges happen to connect the vertices it includes.

3. The missing hypothesis in an edge-count test

Construct a graph with four vertices and three edges that is not a tree. Explain why the edge count does not contradict Proposition 1.3 or the connected-$n-1$ characterization.

Solution

Take edges $\{0,1\}$, $\{1,2\}$ and $\{0,2\}$ on vertex set $\{0,1,2,3\}$. The first three vertices form a triangle and vertex $3$ is isolated. Thus $m=3=n-1$, but the graph is disconnected and cyclic. Proposition 1.3 starts from a tree, so its hypothesis is absent. The converse characterization requires connectedness in addition to the count, and that hypothesis is also absent. The count is a necessary property of trees, not a standalone recognition rule.

4. Every edge in a tree is a bridge

Prove that deleting any edge of a tree disconnects it. Conversely, show that an edge on a cycle in a connected graph is not a bridge.

Solution

Let $\{u,v\}$ be an edge of a tree. If deleting it left the graph connected, a path from $u$ to $v$ would remain. In a simple graph that alternative path has length at least two; adding the deleted edge creates a cycle, contradicting the tree definition. For the converse, let an edge lie on a cycle. The rest of that cycle supplies a walk between the edge's endpoints without using it. Any walk that used the deleted edge can replace that occurrence with this alternative route. Therefore all former reachable pairs remain reachable, and Proposition 1.1 supplies paths if needed. Connectedness survives, so the edge is not a bridge.

5. Extend the edge count to forests

Prove that a forest with $n$ vertices and $c$ components has $n-c$ edges. Apply the formula to the graph obtained by removing $\{2,4\}$ and the diagonal from the teaching network. Is that graph a forest?

Solution

Every component of a forest is connected and acyclic, hence is a tree. If component $i$ has $n_i$ vertices, it has $n_i-1$ edges by Proposition 1.3. Summing over all components gives $\sum_i(n_i-1)=n-c$. In the specified modified graph, the four square edges remain and vertex $4$ is isolated. Thus $n=5$, $c=2$ and $m=4$, whereas a forest on those components would have $n-c=3$ edges. The square is a cycle, so the graph is not a forest. The formula can reject this candidate because its components are independently known.

6. Change the backbone problem

Attach a new vertex $5$ to vertex $4$ by a single new edge. Determine the number of spanning trees of the enlarged graph, the number of edges in each tree, and the number of naive candidate edge subsets. Explain the three answers separately.

Solution

The new edge is forced in every spanning tree because it is the only edge incident with vertex $5$. Removing that edge and vertex gives a bijection with the original spanning trees, so the count stays eight. The enlarged graph has six vertices, so each spanning tree has five edges. There are seven available edges, giving $\binom75=21$ candidate five-edge subsets for naive enumeration. The count of valid designs has stayed constant even though both the graph size and the candidate search space have increased. These are different quantities.

1.11 What is established and what comes next

The chapter establishes the graph model, the distinction between walks and paths, the component partition, the two-leaf theorem, the tree edge count, and the connected-$n-1$ recognition criterion. It counts the eight spanning trees of one explicit network by a complete combinatorial argument and reproduces that count with a determinant. No general determinant-counting theorem has yet been proved here.

The assumptions are finite, simple, undirected and unweighted graphs with at least one vertex. Directed reachability loses the reversal argument; parallel edges need separate identities; weights change what a tree sum means. A cyclic graph can contain many spanning trees while still depending on one bridge. The structural model does not choose an optimal backbone or describe failure probabilities.

The source sequence is Ranveer Singh, Warm-up with graphs, including its three tree exercises and final matrix question. The external mathematical reference is the author-hosted Brouwer–Haemers preprint, §§1.1 and 1.3.5; the cited locations were inspected. The reader can now formulate a spanning-tree counting problem without conflating a connected subgraph, an induced subgraph and a spanning subgraph. The next step is to encode edge orientations in a matrix whose determinants detect exactly the tree selections counted above.
